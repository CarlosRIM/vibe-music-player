# 🎧 VIBE Music Player

Player de música cyberpunk moderno desenvolvido com React + Vite + PWA.

---

## ✨ Recursos

- 🎵 Reprodução local de músicas
- 🎤 Karaokê sincronizado
- 📂 Upload de arquivos MP3
- 🎚 Controle de volume
- 🔀 Shuffle / Repeat
- 📱 PWA instalável
- 🌈 Interface cyberpunk moderna
- ⚡ Visual moderno estilo streaming app

---

## 🚀 Tecnologias

- React
- Vite
- PWA
- Web Audio API
- CSS Moderno
- Capacitor (Android APK)

---

## 📦 Instalação

```bash
npm install
```

---

## ▶ Rodando localmente

```bash
npm run dev
```

Abra:

```bash
http://localhost:5173
```

---

## 🏗 Build de produção

```bash
npm run build
```

---

## 📱 APK Android (Capacitor)

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android

npx cap init "VIBE" "com.vibe.app" --web-dir=dist

npm run build

npx cap add android

npx cap sync

npx cap open android
```
